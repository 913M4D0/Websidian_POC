| 단순 텍스트 기준선       |   71.43% |    85.71% |  78.85% |             40.00% |           26.67% | 해당 없음 |  해당 없음 |       해당 없음 |
| Websidian 평면 검색      |   71.43% |    90.48% |  84.54% |             36.67% |           20.00% | 해당 없음 |  해당 없음 |       해당 없음 |

`Top-10 비관련 슬롯`은 검색 결과 슬롯 중 해당 시나리오와 무관한 ID 비율로, 전체 음성 문서를 분모로 하는 통계학적 FPR가 아닙니다. 관계 경로 역시 원인이나 사실을 증명하지 않고, 확인할 원문으로 이동하는 탐색 경로만 뜻합니다.

## 공개된 한계와 다음 개선점

1. `WS-008` 시나리오에서 `WS-006`은 depth 2로 회수됐지만, 정답이 고정한 강한 경로 `WS-005 → WS-006` 대신 `WS-007 → WS-006`을 선택했습니다. 대상 회수는 성공했으나 엄격 경로 판정은 실패해 전체 path recall이 83.33%입니다.
2. 대표 24건은 제품 시연용으로 설계한 합성 시나리오입니다. 배경 270건을 포함했어도 실무 분포, 새로운 표현, 권한 경계, 장기 데이터 드리프트를 대표하지 않습니다.
3. qrels는 현재 단일 작성 기준입니다. 제품 순위를 보지 않은 복수 검토자의 독립 라벨과 합의 기록이 있어야 판단 편향을 더 줄일 수 있습니다.
4. 사람 참여 실험이 없으므로 이해 정확도, 판단 속도, 사용자 만족도와 실제 업무 완료시간은 아직 주장할 수 없습니다.
5. 실행 환경과 런타임 부하는 결과에 영향을 준다. 절대시간이 아니라 동일 실행 안의 상대 결과로만 해석해야 합니다.

## 재실행

프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
node --experimental-strip-types scripts/eval-retrieval.mjs `
  --iterations 100 `
  --output-dir evidence/poc-benchmark/results
```

세부 정의와 원본 결과는 다음 파일을 확인합니다.

- `evidence/poc-benchmark/protocol.md`: 실험 설계와 주장 범위
- `evidence/poc-benchmark/scoring-rubric.md`: 지표·관련성·사람 평가 기준
- `evidence/poc-benchmark/task-set.json`: 세 과제의 입력
- `evidence/poc-benchmark/ground-truth.json`: 평가 전용 qrels와 기대 경로
- `evidence/poc-benchmark/results/retrieval-eval.json`: 환경·해시·과제별 전체 결과와 시간 표본
- `evidence/poc-benchmark/results/retrieval-eval.csv`: 평면 결과표
