# WEBSIDIAN 제출 데모 영상

- 파일: `03_WEBSIDIAN_DEMO.mp4`
- 길이: 89초
- 규격: 1920×1080, 30fps, H.264, 무음
- 데이터: 실무 유사 합성 POC 이슈
- 흐름: 3D 기억 성운 → WS-008 검색·선택 → 직접·2단계 이력 탐색 → AI 이슈 분석 → 이력 기반 테스트 케이스 → 결과 복사

분석은 연결된 원문을 사람이 읽기 쉬운 판단 초안으로 바꾸고, 테스트 케이스는 개발자가 자기 구현에서 놓치기 쉬운 과거 재시도·롤백·회귀 조건을 다시 확인하도록 돕는 흐름을 보여줍니다.

## 표현 범위

영상은 실제 Websidian UI와 그래프 상호작용을 자동 조작해 녹화했습니다. 제출 당일 네트워크 또는 모델 지연 때문에 흐름이 끊기지 않도록, 기본 녹화 모드는 브라우저 안에서 미리 정한 합성 평문을 실제 SSE 형식으로 나누어 전달합니다. 따라서 `<<구획>>` 감지, 즉시 카드 생성, 글자 스트리밍, 탭 전환, 복사 기능은 실제 화면 로직이며, 영상 속 AI 문안 자체는 결정론적 시연용 결과입니다. 이 구분은 영상 우측 상단에도 항상 표시됩니다.

실제 OpenRouter 호출로 다시 녹화할 때만 `--live-llm` 옵션을 사용합니다. 이 경우 모델 응답 시간에 따라 영상 길이와 내용이 달라질 수 있습니다.

## 재생성

1. 로컬 사이트를 실행합니다: `npm run dev -- --host 127.0.0.1`
2. `WEBSIDIAN_PLAYWRIGHT_PATH`에 Playwright 패키지 경로를 지정합니다.
3. `WEBSIDIAN_FFMPEG_PATH`에 ffmpeg 실행 파일 경로를 지정합니다.
4. `node scripts/record-submission-demo.mjs`를 실행합니다.

다른 주소에서 녹화할 때는 `--url <주소>`, 다른 출력 위치는 `--output <경로>`를 사용합니다.
