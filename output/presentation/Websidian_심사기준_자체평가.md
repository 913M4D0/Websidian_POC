# Websidian 경진대회 심사기준 자체평가

작성일: 2026-09-10  
평가 대상: 현재 Websidian POC와 15분 발표자료  
참조: `다우키움_AI활용경진대회_상세운영방안(FAQ 포함).pdf`

## 평가 전제

- 참가 분야는 `사내 업무 AI 활용(AX)`으로 판단했습니다.
- 실제 심사 점수 예측이 아니라, 현재 제출물에서 증명 가능한 내용만 반영한 보수적 자체평가입니다.
- 합성 이슈 294건은 기능과 시각화의 시연 범위이며, 업무 성과 표본으로 계산하지 않았습니다.
- 개인 경험과 기대효과는 문제 정의의 근거일 수 있지만, 도입 전후 성과 수치로 계산하지 않았습니다.

## 현재 경쟁력

1. 완료 이슈의 원문을 바꾸지 않고 다음 이슈의 근거로 재사용하는 문제 정의가 선명합니다.
2. 이슈 생성·검색·중복 방지 가져오기·관계 탐색·AI 분석·테스트·완료 기억 전환이 하나의 흐름으로 동작합니다.
3. AI에게 전체 기록을 던지지 않고 현재 이슈와 연결된 원문만 제공하며, 실패해도 확정 기억을 잃지 않는 구조입니다.
4. 플랫폼 종속 분류체계가 아니라 이슈와 관계를 기본 단위로 삼아 다른 부서와 형상기억 도구로 확장할 수 있습니다.
5. 대표 시나리오가 `과거 해결·롤백 재사용`, `기획 의도 확인`, `타팀 변경의 파생 영향 발견`으로 구분되어 발표 가치가 명확합니다.

## 우선 보완점

### P0. 제출 전에 반드시 보완

1. **소규모 비교 실측**
   - 대표 시나리오 3개를 최소 3명 이상이 기존 방식과 Websidian 방식으로 각각 수행합니다.
   - `첫 유효 이력 발견 시간`, `처리 방향 확정 시간`, `불필요 수정 방지 여부`, `추가로 발견한 회귀 조건`, `타팀 영향 발견 시점`을 기록합니다.
   - 결과가 작더라도 표본 수·절차·원자료를 함께 제시하며, 없는 성과를 추정하지 않습니다.

2. **AI 자원 효율 실측**
   - 이슈 분석·테스트 케이스·기억 생성별 `연결 근거 수`, `입력/출력 토큰`, `첫 출력 시간`, `전체 시간`, `비용`, `오류·재시도·폴백률`을 기록합니다.
   - 294건 전체 전달과 2-hop 근거만 전달하는 경우의 컨텍스트·비용 절감률을 비교합니다.

3. **접근 가능한 데모 증빙**
   - 현재 배포 사이트가 소유자 전용이면 심사위원이 링크를 열 수 없습니다.
   - 성운→WS-008 선택→관련 이력→이슈 분석→테스트 케이스→완료 기억 탄생을 담은 2~3분 MP4 또는 PDF 내 실제 화면 캡처를 준비합니다.

4. **AI·외부 API·오픈소스 고지**
   - OpenRouter, 사용 모델, GitHub 연동, 개발 보조 AI, React, Three.js, 3d-force-graph, three-spritetext, Lucide 등 사용 도구와 라이선스를 한 표로 정리합니다.
   - 참고 프로젝트에서 가져온 아이디어와 실제 사용한 코드를 구분합니다.

### P1. 본선 전에 보완

5. **운영·보안 설계**
   - 원문 접근권한, 민감정보 마스킹, 조직별 ACL, 프롬프트 인젝션 방어, 감사 로그, 기억 정정·재개방, 보존·삭제, 비용 상한을 정의합니다.

6. **AI 활용 과정 가시화**
   - `관련 이력 선별 → 근거 제한 프롬프트 → 스트리밍 → 구획 표시 → 확정 기억 검증 → 실패 시 원문 보존`을 한 장으로 설명합니다.
   - 사람의 최종 판단과 AI의 보조 범위를 명시합니다.

7. **발표 안정성**
   - 실제 발화는 13분 30초~14분에 끝나도록 1분 이상의 시연·전환 버퍼를 둡니다.
   - 라이브 호출 실패 시 사용할 녹화 영상, 고정 출력, PDF 캡처를 함께 준비합니다.

8. **전사 확장 근거**
   - 개발 이외에 고객상담, 준법, 운영, 기획 중 1개 업무를 선택해 같은 이슈 순환 구조로 짧은 보조 사례를 만듭니다.
   - `GitHub 전용 서비스`가 아니라 `업무 기록 어댑터를 교체할 수 있는 조직 기억 서비스`임을 명확히 합니다.

## 점수 상승 시나리오

실제 소규모 파일럿과 호출 효율 데이터를 확보하고, 오프라인 데모·라이선스·운영계획을 보강하면 온라인 발표심사는 약 `62점 → 78~82점`, 본선 자체평가는 약 `74점 → 82~86점` 수준까지 개선 여지가 있습니다. 이는 보완 항목이 실제 증빙으로 완성된다는 가정의 내부 목표치이며, 심사 결과를 보장하는 수치가 아닙니다.
